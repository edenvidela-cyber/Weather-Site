Project Name:  

 

Weathervane

 

Project Description:  

 

An Api Weather site made to see the weather in a chosen city. 

 

Technologies:  

 

    HTML

    CSS

    JS  

 

How to Run:  

 

download the owlcarousel zip(latest should work), place in main folder. 
run on a live server with vscode/ internet browser,
Get an API Key from weather api.com and insert it on line 87 of Owl-wisdom.js


 

Features:  

 

OwlCarousel, a site with a Celcius to farhenheight convertor, a search api section to look for your city, and a display section of the weather for a full week.
